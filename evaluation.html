Evaluation protocol

What was scored?

The fixed Treasury snapshot yields 3,466 chronological windows. Training uses the first 2,974, validation the next 246, and testing the last 246. Test targets run from Nov 18, 2025 to Nov 17, 2026. The matched direct models trained for 15 epochs with seed 42; validation daily total MAE selected the checkpoints.

Each issuance contributes five target dates and four channels. Repeated dates from different issuances count as separate forecasts. The weekday baseline averages up to four recent same-weekday observations; the single route uses the recent window and calendar features. CalendarPulse adds target-aligned weekly and annual memory.

The backtest uses observed reporting dates and an assumed publication lag. Prospective use requires an issuance-time calendar and archived releases. These results describe one U.S. snapshot and one matched training seed.

Reported payments

The Treasury’s Daily Treasury Statement, “Income Tax Refunds Issued,” supplies the four reported channels. The project snapshot includes reports through Nov 17, 2026. The source inspector opens the official API for a chosen reporting date.

Held-out forecasts

Export all 4,920 origin–target–channel rows behind the displayed scores. Values are USD millions. Sum channels first; compute absolute errors by target date for daily MAE or by issuance for five-day MAE.

Model and data tooling

TimeNet stores dated windows and cutoffs. OpenTSLM supplies the time-series interface. Gemma 3 270M is the shared backbone.
